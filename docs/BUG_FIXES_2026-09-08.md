# Gameplay follow-up — 2026-09-08

These changes apply to the mounted RC3 preview. They do not change its release version or establish full engine acceptance.

## Changes

| Report | Result | Main files |
|---|---|---|
| Explosion script error | Snapshot damage values before allocating another `DamageInfo`; retain plain snapshots in the blast queue. Missing/removed damage actors fall back to the world. Synthetic relay damage is distinguished from a secondary explosion, with bounded queues and reload-safe wrappers. | `crossing.lua`, `blasts.lua`, `seamless_portal_clone.lua` |
| Intermittent physgun release | Preserve an existing corridor on repeated pickup notifications; prevent a portal/proxy pickup from replacing a confirmed hold. Tracked holds remain outside loose-prop transfer and clone coupling. Remove forced-drop calls from that transfer path. | `holding.lua`, `seamless_portal/init.lua`, `seamless_portal_clone.lua` |
| Visible back with backface disabled | Suppress all drawing behind a linked portal with its back disabled. The waiting outline follows link/unlink state, independently of render-budget decisions or the previous rendered frame. | `seamless_portal/cl_init.lua` |
| Glass impacts / crowbar | Use the default physics surface and suppress local portal impact effects. Continue native crowbar/stunstick damage through a bounded damage-enabled trace; empty remote paths produce no continued hit. Bullet continuation stays in its existing callback. | `seamless_portal/sh_init.lua`, `seamless_portal/init.lua`, `melee.lua`, `traces.lua` |
| AR2 ball displacement | Clear the exit along the transformed flight direction, preserving the oblique trajectory instead of shifting it along the portal normal. Check the exit corridor before moving. | `projectiles.lua` |
| RPG aiming | After transfer, steer the existing missile along the relevant remote aim segment. Temporarily exclude the weapon's original laser from native seeking and supply a remote sprite. Restore the original laser and remove helpers on release of guidance, disable, unlink, removal and cleanup. | `rpg_guidance.lua`, `sh_detours.lua` |

Long, nearly coplanar line traces also ignore a spurious zero-fraction convex portal hit observed with a rotated exit. Crossing rays and hull collisions remain available.

`seamless_portals_damage` and the damage features on both endpoints govern melee and RPG continuation. RPG guidance also obeys `seamless_portals_projectiles`. No new settings or network channels were added. The RPG adapter supports the native player-owned `weapon_rpg`; it retains the missile, owner, speed, collision and detonation behavior, while calculating the remote steering direction in Lua.

## Verification

Offline: **144 passing tests, 2 failing tests**, including **18 new field regressions**. The unchanged failures are C-T42 and C-T43 (sound). Source gates pass. The full validator remains unsuccessful because those failures are retained. LuaLS was run with LuaJIT, GLua syntax extensions and GMod definitions; it still reports dynamic entity/datatable and realm-related warnings, so this is not a clean LuaLS certification.

Native automated probes ran on a local dedicated LAN Sandbox server, `gm_flatgrass`, port 27025, maxplayers 2, with Workshop content disabled. The interactive weapon probes used a server bot with scripted input in an isolated area; there was no human observer. Damage, blast and projectile ConVars were enabled. A timestamped server probe confirmed loading, error monitoring was installed, and the final server error capture was empty.

- After reloading the map/Lua state, native smoke compilation and API checks passed. `util.BlastDamage`, `util.BlastDamageInfo` and a damage-enabled native `env_explosion` each delivered one remote hit of approximately 62.707 damage for the same 100-damage/160-radius setup.
- Physgun: 100 samples during extension and withdrawal; 90 samples with native hold active. The only drop occurred at the commanded release, approximately 9.075 seconds into the probe.
- Crowbar: five remote hits of 10 damage before removing the target from reach; no further remote hits afterward. Portal trace damage was zero.
- Hitscan: one terminal callback and one 17-damage hit on the remote target, with the original attacker.
- Native AR2 secondary fire: an oblique crossing through a rotated exit retained owner and PhysObj; measured perpendicular displacement was about 0.000025 Source units.
- RPG: a 90-degree exit produced the expected outgoing flight direction. Moving aim changed the remote dot and missile velocity over 67 samples. Cleanup restored the original laser owner/visibility, including when the helper disappeared first.

Evidence and temporary probe source are retained outside the addon in `/tmp/seamless-native-20260908`; offline reports are in `/tmp/seamless-validation-20260908-final`. Temporary runtime probes were removed from the addon.

No manual graphical-client test was performed. Backface rendering and audible/predicted impacts still need client confirmation. Physgun retention with constrained assemblies, blocked exits, player crossing and a second multiplayer observer remains native acceptance work. Native barrel chain reactions and comprehensive clone collision recovery remain outside the demonstrated results; the chain-event distinction has an offline regression.
